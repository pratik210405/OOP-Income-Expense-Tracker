# OOP Income & Expense Tracker

A simple Income and Expense Tracker developed using Object-Oriented PHP.

## Features

- Add Income
- Add Expense
- Edit Transaction
- Delete Transaction
- View All Transactions
- Calculate Total Income
- Calculate Total Expense
- Calculate Balance
- MySQL Database Connection
- Responsive Design

## Technologies Used

- PHP 8+
- MySQL
- PDO
- HTML5
- CSS3
- JavaScript
